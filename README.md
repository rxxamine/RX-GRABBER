## 📖 Installation & Usage

1. **Prerequisites**: Ensure [Python 3.10+](https://www.python.org/) is installed and added to your System PATH.
2. **Library Setup**: Open your terminal and run: `pip install customtkinter`.
3. **Configuration**: Launch `rx_builder.py` and enter your Discord Webhook.
4. **Build**: Click **INITIALIZE BUILD** and retrieve your compiled file from the `/dist` directory.
